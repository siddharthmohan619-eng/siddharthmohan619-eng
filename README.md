## ⚡ The person behind the code

I'm **Siddharth**, pursuing a **B.Tech in Computer Science and
Engineering with an AI & ML specialization**.

As a **Team Captain and Lead AI Developer**, my focus spans deep
learning architectures, geospatial weather nowcasting, explainable
medical imaging, and the engineering needed to deploy models.

I’m interested in the whole journey: understanding a problem,
designing the model, examining its behavior, and making it run efficiently.
